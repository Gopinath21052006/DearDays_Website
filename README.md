# DearDays website

Static site: HTML, CSS, vanilla JS, GSAP + ScrollTrigger + Lenis (loaded from CDN, internet needed).

## Run
Open `index.html` in a browser, or from this folder run `python3 -m http.server 8000` and visit http://localhost:8000

## Structure
- `index.html` page markup
- `css/style.css` styles and design tokens
- `js/main.js` navigation and GSAP animations
- `assets/images/` your app screenshots and cassette illustration
- `assets/apk/` and `deardays-v1.0.0-release.apk` (75.4 MB) production release APK linked directly to the download buttons.
